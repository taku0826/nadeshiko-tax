# ナデシコ源泉徴収計算機 🌸

**登録不要・完全無料・データはどこにも送信されない**フリーランス・個人事業主向けの源泉徴収計算機です。

👉 **今すぐ使う:** https://taku0826.github.io/nadeshiko-tax/

## 機能

- 💴 **報酬額から計算** — 報酬額(税抜)を入力 → 源泉徴収税額・手取り額を自動計算
- 🔄 **手取りから逆算** — 希望手取り額を入力 → 請求書に書くべき報酬額を逆算
- 📋 **計算結果のコピー** — ワンクリックでテキストコピー
- 📖 **解説付き** — 源泉徴収の仕組みと計算式を表示
- 🔒 **完全ローカル動作** — サーバーに一切データを送信しません。入力内容はあなたのブラウザの中だけ

## 計算式

| 報酬額(税抜) | 計算式 |
|------|------------|
| 100万円以下 | 報酬 × 10.21% |
| 100万円超 | 102,100円 + (報酬−100万円) × 20.42% |

復興特別所得税(2.1%)込み、1円未満切り捨て。

※ 源泉徴収の対象となる報酬は所得税法で定められたものに限られます(原稿料・デザイン料・講演料・士業報酬など)。司法書士報酬など一部は計算式が異なります。判断に迷う場合は税理士・税務署にご確認ください。

## 仕組み

単一のHTMLファイルだけで動作します。ビルドなし、依存ライブラリなし。
`index.html` をダウンロードしてオフラインで使うこともできます。
